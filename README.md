# Cashflow — Telegram-бот записи на игры

Бот рассказывает про игру CASHFLOW и записывает людей на ближайшие даты.
Расписание и записи живут в CRM (`~/Desktop/CashflowCRM`), бот ходит туда
по HTTP — своей базы игр у него нет.

Бот детерминированный: никакого ИИ, только кнопки и готовые тексты
(`cashflow_bot/templates.py`). Поэтому цена, адрес и время всегда
корректны — они приходят из CRM, а не из головы модели.

## Что умеет

| Сценарий | Как работает |
|---|---|
| Рассказ об игре | 4 экрана по кнопке «Дальше»: что это, что делаете за столом, как проходит вечер, кому подходит |
| FAQ | Частые вопросы одним сообщением |
| Запись | Дата → мест → имя → телефон → бронь в CRM. Имя и телефон постоянных гостей не спрашиваем второй раз |
| Мои записи | Список броней, кнопки «Буду» / «Не смогу» |
| Дожимы | Начал запись и не закончил → 3 касания (через 30 мин, 6 ч, 24 ч), дальше не пишем |
| Напоминания | За сутки (с подтверждением участия) и в день игры |

Переписка дублируется в CRM — менеджер видит её в карточке сделки.

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и CRM_BOT_TOKEN
python -m cashflow_bot
```

`CRM_BOT_TOKEN` — то же значение, что `BOT_API_TOKEN` в переменных CRM.
Без него бот работает, но записать никого не может: расписание берётся
из CRM.

## Деплой

Railway, `railway.json` уже в репозитории: сервис-worker, старт
`python -m cashflow_bot`, поллинг (вебхук не нужен). Переменные — те же,
что в `.env.example`.

⚠️ SQLite (`data/cashflow.db`) хранит только состояние диалога, дожимы и
отметки об отправленных напоминаниях. На Railway без volume он пропадает
при деплое — потеряются незаконченные записи и человек может получить
повторное напоминание. Записи это не затрагивает: они в Supabase.
Нужен volume — примонтировать на `data/`.

## Структура

```
cashflow_bot/
  __main__.py   вход: поллинг + фоновый планировщик
  config.py     переменные окружения
  handlers.py   диалог: меню, рассказ, запись, свои брони
  keyboards.py  кнопки
  templates.py  все тексты
  crm.py        HTTP-клиент /api/public/* CRM
  storage.py    SQLite: состояние диалога, дожимы, напоминания
  scheduler.py  фоновые дожимы и напоминания
```
